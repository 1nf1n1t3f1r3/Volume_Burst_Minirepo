Backup/Storage Minirepo for Volume Burst Python/Pinescript. Meant for Demonstration, Technical Analysis, or Tinkering; nothing here should be taken as direct Buy/Sell Recommendations.

All of the Pinescripts are available on Tradingview. Simply search their names in the 'Indicator' search button, or search for my Tradingview handle 'Comatus' and add them to a chart to try them out. Alternatively, feel free to Copy/paste them into a script of your own and tinker with them.

The Python script will require it's own environment and dependencies to run, as well as changing the directories.
